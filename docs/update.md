# Feuille de route

1. **IMPLEMENTED / TESTED** : identité OAuth, session, RBAC, utilisateurs et audit.
2. **DESIGNED** : contrat REST/OpenAPI, modèle d’infrastructure, stratégie stockage objet.
3. **PLANNED** : PostgreSQL autonome, inventaire, agents/exporters, métriques, alerting, incidents, tickets, sauvegardes et documentation d’équipements.
4. **PLANNED** : notifications aux responsables à l’ouverture, reconnaissance et résolution d’une alerte.
