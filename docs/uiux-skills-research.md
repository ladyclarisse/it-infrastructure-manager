# Recherche des ressources UI/UX — Étape 6

## UI UX Pro Max

Source officielle consultée : https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Le projet fournit un CLI avec `npm install -g ui-ux-pro-max-cli`, puis `uipro init --ai ...`. Il expose une base de styles, palettes, associations typographiques, règles UX et recherches de design system via des scripts Python. Dans cette session, la ressource a été consultée comme référence de méthode ; elle n’a pas été installée comme plugin global car la refonte est exécutée dans l’environnement WebDev et aucun mécanisme de plugin local correspondant n’est disponible automatiquement.

## Impeccable

Source officielle consultée : https://impeccable.style/

La ressource recommande `npx impeccable install`, puis `/impeccable init`, et décrit un workflow de hooks qui inspectent les modifications UI, détectent des marqueurs d’AI slop et renvoient des constats à l’agent. Dans cette session, le site et son workflow ont été consultés comme référence ; le package n’a pas été installé ni exécuté comme plugin externe dans le projet. Les audits ci-dessous doivent donc être présentés comme des audits internes guidés par ces principes, et non comme des scores officiels produits par ces outils.

## Conséquence de traçabilité

Aucun score UI UX Pro Max ou Impeccable ne sera inventé. Les scores attribués au projet seront explicitement qualifiés comme une évaluation interne visuelle si les outils officiels ne sont pas installés/exécutés dans le contexte courant.
